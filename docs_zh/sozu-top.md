# Sōzu Top —— 拓扑仪表板

## 概览

`sōzu top` 是一个 TUI 仪表板，用于实时查看当前负载、
健康状态和关键指标。它可视化集群配置和后端健康。
与 Prometheus + Grafana 互补 —— 这些是面向历史的视图，
而 `sozu top` 显示"此刻"。

仪表板支持按集群过滤，并提供关于后端状态、
连接数和活跃流的可见性。

## 用法

```bash
sozu top
sozu top --config /etc/sozu/configuration.toml
sozu top --cluster my-cluster
sozu top --detail backend
sozu top --detail cluster
sozu top --lease-ttl-seconds 300 --detail backend
```

## 键绑定

| 键        | 动作                                         |
| --------- | -------------------------------------------- |
| `q` / `Ctrl+C` | 退出仪表板                            |
| `/`       | 输入过滤表达式                               |
| `Esc`     | 清除过滤器                                   |
| `d`       | 切换详细级别（`Backend` ↔ `Cluster`）         |
| `L`       | 增加 `lease_ttl_seconds`（默认 5 分钟）       |
| `l`       | 减少 `lease_ttl_seconds`（最小 30 秒）        |

## 详细级别

`sōzu top` 支持两种详细级别：

- **集群**（`--detail cluster`）：按集群聚合指标。
  更低的基数，适合大规模集群。
- **后端**（`--detail backend`）：按后端展示指标。
  更高的基数，适合诊断目的。

详细级别由 `lease_ttl_seconds` 控制——
worker 内存中维护的每个详细级别视图都有独立的 TTL，
因此切换到另一个级别时旧视图会被清除，
新视图从零开始聚合。

## 指标可见性

| 屏幕        | 显示的指标                                |
| ----------- | ----------------------------------------- |
| 集群概览      | 后端状态（UP/DOWN/ALL_DOWN）、连接数      |
| 后端状态      | 每个后端的指标、流计数                      |
| 健康检查    | 后端连续失败/成功次数                     |
| 连接追踪    | 当前活跃前端连接数、峰值                    |
| 错误追踪    | 每秒错误率                                |
